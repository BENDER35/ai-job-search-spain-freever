# StudentJob (www.studentjob.es) URL reference

## Search

`https://www.studentjob.es/ofertas?search[keywords_scope]=<q>&page=N`

- Location is filtered client-side (the board has no server-side location param on keyword search).

## Detail

`https://www.studentjob.es/ofertas/<id>-<slug>`
